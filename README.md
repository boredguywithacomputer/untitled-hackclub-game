# The Ice House (Name not finalized)

tl;dr a game made on godot by 4 teenagers that lowk don't know what they're doing.

This is a 3D game made in the Godot engine! You play by running around the map and avoiding the enemy, and by running into the many colorful clubes spread around the place, you can play minigames, which winning enough of will let you win.

This is most definetly a work in progress; we are NOWHERE near done. If you want to check the game in it's (somehow) workable state that it is currently in, you can see it in early access on itch at the link attached to the README!
